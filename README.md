# 🏠 EstateX – Mumbai Real Estate Price Prediction

EstateX is a Machine Learning-based web application that predicts residential property prices in Mumbai using various property features such as location, area, number of bedrooms, parking availability, and other property attributes.

The application also provides interactive visualizations and market insights to help users better understand real estate trends across different locations.

---

## 🚀 Features

- Predict property prices based on user inputs
- Interactive and user-friendly dashboard
- Location-wise property analysis
- Area vs Price visualization
- Average property price comparison
- Price distribution analysis
- Real estate market insights
- Fast and accurate predictions using Machine Learning

---

## 📊 Dashboard Preview

The dashboard allows users to:

- Select property location
- Enter carpet/built-up area
- Specify number of bedrooms
- Choose parking availability
- View predicted property price instantly
- Explore interactive charts and analytics

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/EstateX.git
cd EstateX
```

### Create virtual environment

```bash
python -m venv venv
```

### Activate environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / Mac

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will start on:

```bash
http://localhost:8501
```
